How it works

  1. Photograph good parts. No defect photos, no labelling.
  2. A pretrained vision network memorises what every small patch of a good part looks like.
  3. Any patch that doesn't match normal lights up. Too far from normal means reject.

For engineers: a from-scratch PatchCore (CVPR 2022) re-implementation, ResNet-18 features, a greedy-coreset memory bank, exported to ONNX. Code and full benchmark.
